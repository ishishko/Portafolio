# Registro de Agentes Operativos

## @pm (Project Manager)
- **Responsabilidad:** Asegurar que los requerimientos del usuario se traduzcan en tareas accionables y que se respete el "Vibe" del proyecto.
- **Enfoque:** UX/UI, Priorización, Revisión de AGENTS.md.

## @engineer (Lead Developer)
- **Responsabilidad:** Implementar soluciones técnicas sólidas siguiendo el SoC y los patrones de Astro.
- **Enfoque:** Código limpio, Performance, Integración de IA.

## @qa (Quality Assurance)
- **Responsabilidad:** Validar que los cambios sean responsivos y libres de errores sintácticos o visuales.
- **Enfoque:** Testing visual, Cross-browser compatibility, Edge cases.
